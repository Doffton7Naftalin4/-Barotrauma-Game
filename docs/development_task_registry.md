Назначение: единый список состояния задач. Статусы отражают последние прямые сообщения пользователя; написанный код сам по себе не считается проверенным результатом.

## Правила статусов

- **Выполнено** — пользователь подтвердил работоспособность или результат проверен согласованным тестом.
- **В процессе** — работа уже ведётся, но не завершена.
- **Ожидает реализации** — функция ещё не реализована.
- **Требует диагностики** — есть нестабильность или ошибка, причина/обстоятельства ещё не установлены.
- **Не исправлено** — проблема подтверждена и остаётся открытой.
- **Требует проверки** — статус не был заново подтверждён; нельзя считать задачу выполненной.

## 6. Правила ведения реестра

1. Не удалять старые задачи при актуализации; менять статус и добавлять датированные заметки.
2. Не переводить задачу в «выполнено» только на основании внесения кода.
3. Различать статическую проверку, автоматические тесты, браузерный плейтест и подтверждение пользователя.
4. Если функция нестабильна, фиксировать её как требующую диагностики, а не как выполненную.
5. Перед изменением игрового HTML сначала создавать точную резервную копию и проверять её совпадение.
6. После каждого изменения фиксировать файл, суть изменения, проверку, результат и известные ограничения в журнале.
7. Сверять реестр с игровым HTML и сообщениями пользователя; не подменять фактическое состояние предположениями.
