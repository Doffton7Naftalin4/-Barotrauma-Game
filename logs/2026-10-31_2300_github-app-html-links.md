## Подтверждён способ открытия игровых сборок в GitHub App на Android

- **Контекст:** пользователь сообщил, что ранее ссылки на HTML-сборки открывались непосредственно в приложении GitHub, но последняя ссылка формата `raw.githubusercontent.com` / прямого скачивания открывала внешний браузер.
- **Проверенное решение:** ссылка вида `https://github.com/OWNER/REPO/blob/COMMIT/PATH/FILE.html` открыла нужный файл непосредственно в приложении GitHub.
- **Сборка:** `Barotrauma_Dugong_World_Repair_vehicle-camera_hatch-water.html`.
- **Commit сборки:** `311b6dd86425138232c1233b88e409b3b0a7a54f`.
- **Ссылка:** https://github.com/Doffton7Naftalin4/-Barotrauma-Game/blob/311b6dd86425138232c1233b88e409b3b0a7a54f/Barotrauma_Dugong_World_Repair_vehicle-camera_hatch-water.html
- **Подтверждение пользователя:** «Да эта ссылка открывает файл в приложении».
- **Решение на будущее:** для игровых HTML-сборок, которые пользователь хочет открыть в GitHub App на Android, использовать GitHub blob-ссылки с точным commit SHA и путём. Не использовать raw/direct-download ссылки для этого сценария.
- **Проверки:** пользователь подтвердил фактическое открытие ссылки в приложении. Это проверка маршрутизации ссылки, а не игрового поведения самой сборки; игровой тест по-прежнему ожидает.
