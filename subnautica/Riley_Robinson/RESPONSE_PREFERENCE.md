# Response preference

After each successful GitHub progress save for this Subnautica roleplay campaign, respond with exactly:

`Прогресс сохранён!`

Do not list updated files, log names, branch names, or commit details in the confirmation unless the user explicitly asks for them.

## Язык игровых названий
- Все названия предметов, существ, биомов, технологий и других игровых объектов писать только на русском языке.
- Не добавлять английские оригинальные названия в скобках или рядом: они не помогают пользователю и лишь занимают место.
- Это правило действует во всех игровых ответах, инвентарях, описаниях и заметках кампании.


## Отображение показателей выживания
- Когда КПК открыт, показывать точные числовые показатели здоровья, кислорода, голода и жажды в процентах (если соответствующий показатель действительно доступен).
- Когда КПК закрыт, Райли не видит точных процентов: описывать состояние только приблизительно, через ощущения и признаки (например, голод, жажда, нехватка воздуха).
- Не выдавать приблизительные оценки за точные игровые значения. Точные значения показывать только после проверки через КПК.

## Отображение заряда батарей
- В инвентаре и при проверке предметов показывать остаток заряда батареи прямо рядом с названием и количеством, в процентах.
- Обновлять процент после каждого действия, расходующего заряд.
- Не придумывать заряд: если точное значение неизвестно или не проверено, прямо указывать, что оно неизвестно.
